## 🎯 แนวทางการพัฒนาต่อและการส่งต่อข้อมูลระบบ (Developer Handoff Guide)
หากคุณครูนำโฟลเดอร์นี้ไปเปิดพัฒนาต่อในเครื่องโน้ตบุ๊กใหม่ หรือนำสคริปต์นี้ไปให้โปรแกรมเมอร์/ระบบ AI อื่นทำต่อ ข้อมูลสำคัญดังต่อไปนี้จะช่วยให้เริ่มงานต่อได้ในทันที:

1. **การแก้โค้ดหลัก**: ไฟล์โค้ดจริงมีเพียง 3 ไฟล์อยู่ที่หน้าแรก คือ `index.html` (โครงสร้าง), `style.css` (การออกแบบสไตล์ Glassmorphism), และ `app.js` (สคริปต์และการควบคุม API)
2. **การรันในเครื่อง (Local Development)**: คุณครูสามารถใช้ VS Code ร่วมกับปลั๊กอิน Live Server เปิดรันไฟล์ `index.html` ได้โดยไม่ต้องติดตั้ง Server ใดๆ หรือจะรันแบบเปิดไฟล์ตรงๆ ก็ได้เนื่องจากระบบติดต่อผ่านคลาวด์ REST API ของ Supabase อยู่แล้ว
3. **การแก้ไขฟิลเตอร์หรือเกณฑ์ประเมินความเสี่ยง**: สามารถเข้าไปแก้เงื่อนไขได้ที่ฟังก์ชัน `checkFinancialRisk(student)` (ด้านการเงิน) และ `checkSubstanceRisk(smokeVal, behaviorVal)` (ด้านสารเสพติด) ในไฟล์ `app.js` ซึ่งถูกรวมเป็นระบบศูนย์กลางไว้เรียบร้อยแล้ว
4. **ความปลอดภัยของฐานข้อมูล**: Supabase RLS มีนโยบายสิทธิ์แบบเปิดให้ anonymous ดึงและอัปเดตข้อมูลนักเรียนได้โดยตรงผ่าน Headers API Key การควบคุม RLS เพิ่มเติมในอนาคตสามารถทำได้ผ่านหน้าเว็บพอร์ทัลของ Supabase ในหัวข้อ SQL Editor หรือ Table Editor

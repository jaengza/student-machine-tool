# 🚀 คู่มือการอัปโหลดโค้ด & คลังบันทึกรหัสผ่านโครงการ (Upload & Credentials Guide)
เอกสารฉบับนี้จัดทำขึ้นอย่างละเอียดเพื่อสองจุดประสงค์หลัก:
1. อธิบายขั้นตอนการอัปโหลดโค้ดระบบขึ้นเว็บไซต์จริง (GitHub Pages) เพื่อให้คุณครูประจำชั้นและระบบ AI สามารถอ่านทำความเข้าใจและทำตามได้ทันที
2. บันทึกรายชื่อบัญชี รหัสผ่าน และสิทธิ์การเข้าถึง (Credentials) ทุกจุดในโปรเจกต์นี้เพื่อกันลืม และสามารถเปิดดูอ้างอิงได้อย่างสะดวกรวดเร็ว

## 🚀 ส่วนที่ 1: ขั้นตอนการอัปโหลดโค้ดขึ้นเว็บจริงอย่างละเอียด (How to Upload/Push Code)

ในการแก้ไขหน้าตาเว็บหรือคำนวณในโน้ตบุ๊ก เมื่อแก้โค้ดเสร็จแล้ว จำเป็นต้องอัปโหลดไฟล์ขึ้นสู่ **GitHub Pages** เพื่อให้ระบบจริงบนคอมพิวเตอร์และมือถือออนไลน์เป็นเวอร์ชันล่าสุด โดยมี 2 วิธีหลักดังนี้ครับ:

### วิธีที่ 1: การอัปโหลดผ่านโปรแกรมกราฟิก GitHub Desktop (แนะนำสำหรับคุณครู - ง่ายที่สุด)
หากคุณครูใช้โปรแกรม GitHub Desktop บนโน้ตบุ๊กใหม่ ให้ทำตามข้อต่างๆ ดังนี้ครับ:
1. เปิดโปรแกรม **GitHub Desktop**
2. โปรแกรมจะตรวจจับการแก้ไขไฟล์อัตโนมัติ และแสดงรายชื่อไฟล์ที่แก้ไขในแถบด้านซ้าย (เช่น `index.html`, `app.js` สีเขียวหรือเหลือง)
3. ที่ช่อง **Summary (required)** ด้านซ้ายล่าง ให้พิมพ์ข้อความสั้นๆ อธิบายการแก้ไข (เช่น `อัปเดตตัวกรองการเงิน` หรือ `แก้ไขดีไซน์มือถือ`)
4. กดปุ่มสีน้ำเงิน **"Commit to main"** เพื่อบันทึกประวัติไว้ในเครื่อง
5. กดปุ่ม **"Push origin"** (หรือ Fetch origin แล้ว Push) ที่แถบเมนูด้านบน เพื่อส่งไฟล์ทั้งหมดขึ้นเว็บจริง
6. **ผลลัพธ์**: เว็บไซต์ออนไลน์ของคุณครูจะเปลี่ยนเป็นเวอร์ชันล่าสุดทันทีใน 1 นาทีครับ!

### วิธีที่ 2: การอัปโหลดผ่านคำสั่ง Terminal / Command Line (สำหรับ AI หรือโปรแกรมเมอร์ระบบ)
หากส่งงานผ่านระบบ Terminal หรือเปิดผ่าน VS Code Terminal ให้ใช้คำสั่งมาตรฐานดังนี้ในการอัปโหลด:
```bash
# 1. ยืนยันไดเรกทอรีทำงาน
cd "G:\My Drive\student-database"

# 2. เพิ่มไฟล์ทั้งหมดเข้าสู่สเตจเตรียมบันทึก
git add -A

# 3. บันทึกประวัติการเปลี่ยนแปลง
git commit -m "คำอธิบายการแก้ไขของคุณครูหรือระบบ AI"

# 4. อัปโหลดขึ้นสู่คลาวด์ GitHub Pages
git push origin main
```
